## How to use this vault

- **In Obsidian** — open the `knowledge/` directory as a vault. Wiki links,
  tags, frontmatter, callouts, and the graph view all work. Tags are listed
  per page; filter the vault with the tag pane.
- **For skills** — read pages by `<id>` (for example, `[[section-m]]`) or by
  folder path. Skills traverse the graph by following `[[ ]]` links and by
  grepping the vault for references to a given id.
- **To add a page** — follow
  [../conventions/entity-pages.md](../conventions/entity-pages.md): one
  concept per page, the frontmatter (id, type, title, tags, sensitivity,
  source, confidence, provenance, updated), a synthesized summary, and a
  typed Links section.
