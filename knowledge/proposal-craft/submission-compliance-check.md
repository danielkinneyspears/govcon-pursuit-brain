# Submission Compliance Check

The **final production check** — verifying the proposal will be **accepted
and evaluated** (rather than rejected for a format technicality) before
submission. Distinct from the [[white-glove|White Glove review]], which is
the human quality pass over the produced package; this check is the
rules-conformance pass.

## What it verifies

- **Page limits** per volume — counting only what counts (per
  [[section-l]]).
- **Format rules** — font, point size, margins, spacing, line-count rules.
- **File rules** — file format (commonly PDF, searchable), file naming,
  file size limits.
- **Volume separation** — price and cost information appear **only** where
  permitted; the technical and management volumes carry no price content if
  Section L bars it.
- **Forms, representations, certifications** — cover form (SF 33 / SF 1449
  / other), [[section-k-representations-and-certifications|Section K reps
  and certs]], solicitation-specific certifications, amendment
  acknowledgments, active SAM registration.
- **Submission mechanics** — method, destination, exact due date and time
  and time zone, portal registration, delivery confirmation.
- **Mandatory requirement closeout** — every mandatory row of the
  [[compliance-matrix]] at status **Compliant**.

## Late is late

FAR **15.208** governs late proposals and is strict. Plan to submit with
margin; portals fail, uploads run long.

> [!warning] One failed item is go/no-go
> An over-length volume, a missing certification, or misplaced price
> information is not a minor note — it is a reason the proposal could be
> rejected without evaluation. Treat each as binary.
