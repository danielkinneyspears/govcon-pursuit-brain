# Contract Data Requirements List (CDRL)

The list of data deliverables a contract requires — reports, plans, drawings,
test results, status updates, technical data. Each line of the CDRL is a
deliverable; individual items are DD Form 1423 (DoD) or an agency equivalent.

## Key facts

- A CDRL line item specifies the deliverable, the data item description (DID)
  it conforms to, the recipient, the frequency, the format, and any markings.
- CDRLs flow from the [[statement-of-work]] or [[performance-work-statement]] —
  every required deliverable should appear on the CDRL.
- Each CDRL line is a row in the [[compliance-matrix]] (a thing the offeror
  must commit to deliver).
- Failing to deliver a CDRL item, or delivering late, can be a basis for
  performance issues and a [[cpars]] hit.
