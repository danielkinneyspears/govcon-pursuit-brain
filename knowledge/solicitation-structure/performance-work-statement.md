# Performance Work Statement (PWS)

A performance-based statement of work that defines the **outcomes** the
contractor must achieve and the **standards** by which those outcomes are
measured. It states *what good looks like*, not the method. A PWS is normally
paired with a [[qasp]] that explains how the government will surveil
performance.

## Key facts

- Performance-based acquisition is the government's preferred approach for
  services (FAR 37.102): describe results, let the contractor propose the how.
- Each performance requirement carries an objective standard (a measurable
  metric and an acceptable quality level).
- A PWS supports innovation: the contractor can propose a leaner or richer
  approach so long as outcomes are met. Under [[best-value-tradeoff]], richer
  methods can earn strengths; under [[lpta]], the leanest acceptable approach
  wins.
- Proposal sections that respond to a PWS should map each performance standard
  to the corresponding approach element in the [[compliance-matrix]].
