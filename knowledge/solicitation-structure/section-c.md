# Section C — Description / Specifications / Statement of Work

Section C is **the requirement** — the work to be performed. It is delivered
as a [[statement-of-work]], a [[performance-work-statement]], or a
[[statement-of-objectives]], often as a Section J attachment.

## Key facts

- **SOW** — a prescriptive description of the work: what to do, often how.
- **PWS** — a performance-based statement: the required outcomes and the
  standards by which they are measured, paired with a [[qasp]]. It states
  *what good looks like*, not *how*.
- **SOO** — a statement of the government's objectives; the offeror proposes
  the SOW/PWS. Maximum solution freedom.
- Read order is **M, then L, then C** — the requirement (C) is the work
  committed to; M is how that work is scored; L is how the response is organized.
