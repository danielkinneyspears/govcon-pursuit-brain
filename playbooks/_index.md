# Playbooks: Role and Scenario Guides

Playbooks tell **a specific person** how to use this package on a real
pursuit. They are not skills and not entity pages. They are the day-by-day,
gate-by-gate orientation that turns the package from a "knowledge graph" into
a working operating system for that role.

Each playbook says, in plain terms: what you do, what entity pages you create
or update, which skills you run, what views you read, and where the common
mistakes are.

## Current playbooks

- [[capture-manager]] — Capture Manager, gate by gate, from opportunity ID
  through bid validation.
- [[proposal-manager]] — Proposal Manager, kickoff through submission,
  through the proposal phase.
- [[sme-data-call]] (Subject-Matter Expert. The "20-minute SME mode") short
  data calls that translate into proposal entities without making the SME
  read the RFP.

Add a playbook by following the same lightweight format these use: a clear
audience, gates or stages, what to create and update, what to read, and the
common failure modes that recur for that role.
